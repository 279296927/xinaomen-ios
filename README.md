# 新澳门 · iOS 独立版（单文件，自带数据）

把原 Android App（`com.laok.xam`，v3.1）1:1 移植成 **iOS 手机可独立运行**的形态。

**一条边界先说明**：本机是 Android，没有 macOS / Xcode，**产不出 `.ipa`**（这是苹果的签名体系限制，绕不过去）。
所以 iOS 端做成 **单文件网页 App**：iPhone 上打开这一个文件 → 「添加到主屏幕」→ 桌面图标、全屏无地址栏，
体验等同原生 App，**不需要电脑、不需要装任何东西、不需要连 Wi-Fi**。

**关键**：最近 **150 期真实开奖数据直接写死在文件里**。
所以哪怕手机处于飞行模式、或这个文件是从聊天记录里点开的，**打开就是完整内容**——冷门、杀生肖、推荐、走势、爆冷标记全部立刻能算能用；联网时再自动增量更新到最新。

## 二、怎么装到 iPhone 上

### 方式 A：直接传文件（**推荐，完全独立**）

1. 把 `index.html` 通过 **AirDrop / 微信 / QQ / 邮件** 发到 iPhone
   - 微信里点开 → 右上角「…」→ 用其他应用打开 → 存到「文件」
2. 打开 iPhone 的 **「文件」App → 我的 iPhone**，点这个 `index.html`
   - 会自动用 **Safari** 打开，直接就能用了
3. 想当 App 用：Safari 里点 **分享 → 添加到主屏幕 → 添加**
4. 桌面出现「新澳门」图标，点开即全屏运行

> 此时手机**不需要电脑、不需要同一 Wi-Fi、不需要任何服务器**。
> 关掉网络照样能看全部内容（只有「热买榜」「平特一肖图」「在线预测」这类必须联网的模块会提示离线）。

### 方式 B：局域网（可选，用于让它自动同步最新）

1. iPhone 与本机连**同一个 Wi-Fi**
2. 本机执行：`sh /sdcard/Download/solab/XinAomen/ios/start.sh`，会打印形如 `http://192.168.x.x:8899/index.html` 的地址
3. iPhone Safari 打开该地址 → 分享 → 添加到主屏幕

## 三、离线 / 在线行为对照

| 场景 | 表现 |
|---|---|
| 首次打开（含飞行模式） | 立刻显示内嵌的 **150 期**数据，6 个页面全部可用 |
| 联网打开 | 后台自动补齐到最新期 + 拉在线预测，状态栏显示「✓ 已自动同步 · 最新第 xxxx 期」 |
| 内嵌快照已过期后联网 | 自动拉整年历史把缺口填平（不会留空缺期号） |
| 完全无网 | 状态栏显示「离线模式 · 使用内置 150 期数据」 |
| iOS 禁用 `file://` 的 localStorage | 自动降级为**内存态**：本次浏览/计算/存档照常，只是关掉页面不保留；状态栏会如实提示 |
| 六合走势页无网 | 用本地 150 期自己统计（号码/生肖/波色/尾数），页面不留白 |

## 五、内嵌数据（`BOOT_DATA`）

- 内容：最近 **150 期**真实开奖（当前为 `2026139` ～ `2026288`）
- 格式：`期号|开奖时间|波色(r/g/b)|号码(两位补零)|生肖(简体)`，记录间以 `;` 分隔，按时间倒序
- 体积：约 **10.2KB**，注入后 `index.html` 约 88KB（原 70KB）
- 更新方式：
  ```
  node /sdcard/Download/solab/XinAomen/ios/make_boot.js          # 抓取并注入
  node /sdcard/Download/solab/XinAomen/ios/make_boot.js --dry    # 只看结果不写文件
  ```
  幂等：只替换 `var BOOT_DATA='...';` 这一行，其余代码不动；抓不足 100 期会拒绝写入。

## 六、与原版的差异（有意为之）

| 项 | Android | iOS 独立版 | 原因 |
|---|---|---|---|
| 安装包 | APK | 单文件 + 添加到主屏幕 | 无 Xcode，产不出 ipa |
| 首屏数据 | 需联网拉取 | **内嵌 150 期，离线即有** | 支持脱离电脑/局域网独立运行 |
| 数据存储 | SharedPreferences | localStorage（不可用时降级内存态） | 平台等价物 + iOS file:// 限制 |
| 后台轮询 | 前台 60 秒定时 | 前台 60 秒定时（页面隐藏时暂停） | iOS 会冻结后台 JS，顺带省电 |
| 页面切换 | 新建 Activity | 同页 SPA 切换 | 更顺滑，无返回卡顿 |
